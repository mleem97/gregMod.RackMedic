## Installation

Copy `gregMod.RackMedic.dll` to `Data Center/Mods/`. Default shop/workbench keys are F8/F7.

## Build from Source

```bash
dotnet build gregMod.RackMedic.csproj -c Release -p:Platform=x64
```

## Project Structure

Source is under `src/`, current game references under `references/`, and maintenance documentation under `docs/`.
